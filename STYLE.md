# Стилистика блога

Памятка для того, кто продолжит работу над внешним видом сайта, будь то человек или агент. Здесь описано, что уже есть, почему оно так сделано и чего автор не хочет. Перед любой правкой внешнего вида прочитай раздел «Правила».

## Идея

«Ламповый» сайт: тёплый аналоговый вид, собранный из **настоящих артефактов** того, как изображение когда-то показывали и печатали. Это свечение люминофора, кинескоп (CRT), дизеринг, терминальные шрифты, плёночное зерно.

Никакой бутафории: никаких рамок «под фотографию», кнопок-тумблеров, текстур дерева, бумаги или кожи, шрифтов «под старину». Эффект должен быть тихим и системным, а не «смотрите, это ретро».

Блог про математику и программирование вообще, не только про Busy Beaver. Не завязывай оформление на одну статью.

## Правила (из обратной связи автора)

- **Тёмная тема — единственная видимая.** Светлая спрятана (`lightTheme: false` в `src/site.config.ts`): её палитра, правила `[data-theme='light']` и `phosphorLight` остаются в исходниках, но при сборке вырезаются и в сайт не попадают. `lightTheme: true` возвращает переключатель. Новые эффекты делаются для тёмной; если светлую вернут, правило прежнее: любой эффект работает в обеих темах, без деления «тёмная = экран, светлая = печать».
- **Никакого жёлтого.** Палитра остаётся нейтральной: графит плюс оранжевый акцент. Тёплый чёрный, кремовый текст, «бумажная» светлая тема и сплошное оранжевое выделение были отвергнуты как «слишком жёлтые» и удалены. Оранжевый используется только как акцент.
- **Свечение мягкое.** Только широкие размытые слои, без тонкого плотного слоя по контуру букв (он делает буквы жирными и смазанными, «топорно»). Цвет ссылки при наведении не меняется и не тускнеет. Слишком слабое свечение тоже плохо. Принятые значения записаны ниже.
- **Один элемент — один вид.** Индикатор, тег, кнопка-надпись, экран, карточка, свечение выглядят одинаково везде, где встречаются: значения берутся из токенов `global.css`, правило одно (см. «Единая система»). Подстраивать тень, блик или отступ под одно место нельзя — это и есть «слоп». Нужен новый вид — заведи токен и опиши его здесь.
- **Новое добавлять, а не заменять.** Новые эффекты в духе 1-бит (дизеринговая тень, шахматка, «муравьи», пиксельный шрифт) вставляются в отдельные места, а не вместо существующего.
- **Не дизерить все картинки статей.** Главное полотно для эффектов — обложки карточек.
- **Отвергнуто:** функциональные добавки (футер, «предыдущая/следующая статья», серии, интерактивная песочница, деплой); «проявка» картинок при загрузке; градиент «свет лампы» сверху; рассыпание пикселями при переходах; буквицы; анимация включения кинескопа; плашка под номером сноски; общий «позвоночник» через номера в оглавлении; шумный дизеринг линий дерева (линии сплошные); дизерная тень под блоками кода и под карточками статей (`shadow` выключен); усиление свечения блока кода при наведении; сбой синхронизации/мерцание и затемнение/разгорание CRT-обложки карточки при наведении (`hover` выключен); блик на инлайновых `` `code` ``; имя автора в шапке сайта; виньетка/рамка на заглавной картинке `.figure-plate` в тексте; дизерный ореол и галерея со стрелками/счётчиком в лайтбоксе; пиксельная сетка поверх растровых картин в лайтбоксе; блок `Projects` в сайдбаре `About`; загорание заголовка карточки (оранжевый цвет и свечение) при наведении.
- **Сразу в основной код.** Отдельных прототипов только для dev больше нет. Правки вносятся в основной код и проверяются на `npm run dev` (http://localhost:4321).

## Где что лежит

- `src/styles/global.css` — **все токены**: палитра, поверхности, глубина (тени, виньетки, сетка), свечение, тайминги. Плюс кнопки-надписи `.mono-btn`, подписи к картинкам и полноэкранный лайтбокс. Цвет, тень или свечение, которых нет в токенах, не заводи по месту — добавь токен.
- `src/styles/lamp.css` — все эффекты. Каждый висит на классе `html.lamp-<имя>` и только решает, куда какой токен идёт.
- `src/layouts/Base.astro` — список включённых эффектов (`const lamp = [...]`), классы ставятся прямо на `<html>`, плюс шапка сайта. Чтобы выключить эффект, убери его имя из списка.
- `src/scripts/lamp.ts` — поведение: дизеринговые линии (три вида в `LINE`), блик (`paintGlare`), лента прогресса, блочный курсор, искажение на обложке при наведении (выключено), логика оглавления, слой свечения и тонкие полосы прокрутки у кода и поиска.
- `src/scripts/covers.ts` — CRT-обложки карточек на главной.
- `src/lib/og.ts` — превью ссылок (Open Graph), см. ниже.
- `src/lib/code-themes.mjs` — неоново-люминофорные темы подсветки Shiki (`phosphorDark` / `phosphorLight`).
- `src/components/ArticleCards.astro`, `src/components/ProjectCards.astro` — карточки главной; `src/components/Project.astro` — страница проекта.
- `src/components/Toc.astro`, `src/components/Article.astro`, `src/components/Column.astro` — разметка оглавления, колонки и шапки статьи. Дерево оглавления держится на атрибутах `data-depth`, `data-branch`, `data-parent`, `data-first`; их ставит `tocAttrs` из `src/lib/posts.ts` (один и тот же для бокового оглавления, складного и мини-монитора на карточке).

## CRT-обложки (`covers.ts`)

Обложка карточки на главной рисуется на canvas как экран кинескопа:
- каждый пиксель картинки — тройка полосок R, G, B;
- между строками развёртки тёмные промежутки;
- сверху мягкое свечение;
- цвет слегка тёплый.

Белые картинки, например графики, инвертируются по яркости: бумага становится чёрной, цветные линии светятся своим цветом.

Параметры подобраны автором («CRT 1px выглядит очень круто»), без нужды их не менять: шаг тройки 3 CSS px, светится 72% строки, свечение 55% при радиусе 2.5px.

Сам `<img>` только источник, он невидим. Без JS показывается приглушённая картинка. Под заголовком и оглавлением экран притушен маской. Экран загорается медленно, как гаснет свечение (`--lamp-out`).

## Оглавление (`toc`)

- Всё набрано IBM Plex Mono, заголовок `CONTENTS` прописными с разрядкой.
- Номера разделов 01, 02, 03 шрифтом VT323. Подразделы набраны тем же кеглем, что и разделы.
- Подразделы — дерево: под номером раздела, у которого есть подразделы, тонкая черта, опущенная на 4px; от середины черты вниз идёт ствол `┬`, ветки `├─` доходят до заголовков, последняя ветка `└─`. Линии **сплошные**, 1px, цвет `--tree`. Заголовки обоих уровней начинаются в одной колонке.
- Прочитанные пункты приглушаются цветом, а не прозрачностью: прозрачность бледнит и кусок дерева. Текущий пункт светится.
- Слева вертикальная лента прогресса из клеток (3px через 5px), у заполненных клеток мягкое свечение. Заполняется равномерно от «первый заголовок дошёл до линии чтения» до конца страницы, к подсветке пункта не привязана; в самом конце заполняется полностью. Запасной вид `TOC_RAIL = 'scale'` в `lamp.ts`: лента поделена по пунктам и синхронна с подсветкой, а густота клеток следует длине текста раздела (как нелинейная шкала радиоприёмника).
- Скроллбар длинного оглавления скрыт, оно само прокручивается к текущему разделу.
- Оглавление зафиксировано на `top-[94px]` (`48px` хедер + `46px` отступ `<aside>` при `pt-10` у колонки), чтобы не дёргалось у самого верха страницы при `scrollY = 0`.
- На узком экране оглавление — складная плашка над текстом в виде блока кода, с той же рамкой `1px`: шапка `--muted` с оранжевым пикселем, `CONTENTS`, справа `7 SECTIONS` и `[+]`/`[−]`; открытая — дизерная линия под шапкой и экран, как у блока кода (см. «Единая система»), внутри то же дерево.
- Мини-монитор на карточке главной — то же дерево мельче (`11.5px`, ряды по `17px`), номера горят (`--aura-sm`); длинный список сам медленно прокручивается и тает у краёв.

Геометрия дерева рассчитана на пиксели: номер — колонка 18px, ствол на x = 6px, ветка на y = 17px (у первого подраздела 13px, потому что его кусок начинается на 4px ниже). Меняешь отступы — пересчитай.

## Шапка сайта и шапка статьи (`meta`)

**Шапка сайта (`[data-site-header]`):**
- Без имени автора; матовое стекло (`84%` фона + `blur(10px)`) и 2-рядная `1×1px` дизерная граница снизу (плотный ряд сверху).
- Слева только `HOME` с квадратиком `4px` (на главной горит оранжевым со свечением, на остальных страницах приглушённый серый).
- Справа `SEARCH [⌘K]` (в скобках без рамки, как сноски) и, если вернуть светлую тему, `THEME`.
- Все надписи-кнопки сайта — один класс `.mono-btn` (`global.css`): `HOME`, `SEARCH`, `CLOSE [ESC]` в поиске и лайтбоксе; `COPY` на блоках кода такой же, только мельче. IBM Plex Mono `11.5px` прописными, разрядка `0.06em`, серые; при наведении светлеют и получают ореол `--aura`.

**Шапка статьи:** одна строка под заголовком:
- слева теги прописными, IBM Plex Mono `12px`, перед каждым пиксель-индикатор вместо `#`, при наведении он разгорается;
- справа дата `2026-11-19` и `4 MIN READ`;
- без линии под шапкой.

## Блоки кода и инлайновый код (`grille`)

- Подсветка Shiki: неоново-люминофорная палитра `phosphorDark` / `phosphorLight` (`src/lib/code-themes.mjs`).
- Четырёхслойный кинескоп на `.code-block`: экран `<pre>` (см. «Единая система»: поверхность, блик, виньетка, утопление) → чёткий выделяемый код → размытый клон `code.code-glow` (`z-index: 2`, `blur(4px)`, `opacity: 0.36` в тёмной / `0.11` в светлой) → тихая пиксельная + scanline-сетка `.code-block::before` (`z-index: 3`, `mix-blend-mode: multiply`), чтобы свечение само подсвечивало пиксельную текстуру.
- Компактная шапка `.code-bar` (`25px`): пиксель-индикатор перед языком/именем файла (вспыхивает на `COPIED`), кнопка `COPY` (`.mono-btn`, `10.5px`: при наведении светлеет с ореолом, после копирования — оранжевая `COPIED`), снизу ровная 2-рядная дизерная линия.
- Нативный горизонтальный скроллбар скрыт; у прокручиваемых блоков внизу (`bottom: 5px`, `padding-bottom: 19px`) появляется тонкая линия прокрутки: серая направляющая `1px` и светлый ползунок `1.5px` со спокойным нейтральным свечением (без усиления свечения при наведении).
- Инлайновый `` `code` ``: то же утопленное стекло с компактным свечением текста (`5px / 11px`, без сетки и без блика).

## Картинки, подписи и лайтбокс

- У растровых картинок `background-color: transparent` (без `bg-white`, чтобы не было белых точек на скруглениях); курсор при наведении `pointer`.
- Подписи к картинкам: выравнивание вправо, курсив Source Serif 4, 14.5px. Код внутри подписи прямой, без плашки, 0.86em.
- Полноэкранный лайтбокс (`dialog.lightbox`): сверху справа `CLOSE [ESC]` ровно на месте `SEARCH`, подпись курсивом `Source Serif 4` (`15px`) ровно по ширине картинки и выровнена вправо (`display: table` + `table-caption`), одинарная рамка `1px`, виньетка, утопление и тень `--shadow-modal`; тихая сетка `--screen-grid` накладывается только на SVG-диаграммы, растровые картины остаются чистыми.
- Страницу под лайтбоксом закрывает почти непрозрачная вуаль цвета фона с размытием: `CLOSE` и подпись лежат прямо на ней, и сквозь полупрозрачное затемнение они наезжали на `SEARCH` и текст статьи. Окну поиска хватает затемнения `--backdrop-bg`: у него своя поверхность.

## Единая система: стекло, свет, линии

Один и тот же элемент везде выглядит одинаково, потому что берёт одни и те же токены из `global.css` и одно правило из `lamp.css`. Новый элемент того же рода подключается к правилу, а не получает свои тени.

- **Рамка:** везде одинарная `1px solid var(--border)` и скругление `var(--radius)` (`6px`): карточки, блоки кода, складное оглавление, окно поиска, лайтбокс. Без второго светлого канта и без чёрных колец внутри. Чипы инлайнового кода — `3px`, картинки в тексте — `4px`.
- **Два вида стекла:**
  1. *Экран* — стекло в колонке текста: блоки кода, складное оглавление, экран поиска (один селектор в разделе `screens`). Поверхность `--surface-screen`, под текстом блик и виньетка `--vignette-panel`, утопление `--shadow-recess`, поверх текста тихая сетка `--screen-grid`, сверху безель-шапка `--muted` с дизерной линией. Рамка лайтбокса — то же стекло вокруг картинки.
  2. *Трубка* — кинескопы карточек главной (`.tube`, раздел `vignette`). Каждая половина любой карточки — трубка: CRT-обложка статьи и её мини-монитор, обложка проекта и его панель. Поверхность `--surface-tube` (тёмная в обеих темах, в светлой внутри действует тёмная палитра), поверх содержимого стекло: виньетка `--vignette-tube` и глубокое утопление `--shadow-tube`. Сетки на карточках нет.
- **Один источник света — блик (`glare`):** сверху слева под `130°`, 4-ступенчатый дизер Байера `4×4` клетками `2px`, тёплый `[242, 186, 118]` при `alpha 0.042`, спад `2.3`, длина `0.60`. Лежит под текстом на каждом стекле с текстом: экраны (код, складное оглавление, поиск) и текстовые половины карточек (`data-glare`). Картинки (обложки, иллюстрации, лайтбокс) и чипы кода без блика. Белых бликов `155°` и пятен сверху нет нигде.
- **Свет:** всё, что светится, берёт акцент. `--aura` — ореол текста при наведении или выборе (ссылки, кнопки-надписи, сноски, текущий пункт оглавления, выбранный результат поиска); `--aura-sm` — постоянное свечение мелких горящих знаков (номера в мини-мониторе и текущий номер в оглавлении, совпадения в поиске); `--card-aura` — рамка карточки при наведении. У погасшего состояния те же радиусы при нулевой яркости (`--aura-off`), поэтому свет плавно проявляется, а не растёт из точки. Загорается за `--lamp-in`, гаснет за `--lamp-out`.
- **Пиксель-индикатор:** одно правило на все. Квадрат `4×4`, отступ до текста `7px`, цвет акцента (в коллауте — цвет его чернил), свечение своим цветом `--led-idle`; разгорается до `--led-active`, когда то, что он отмечает, наведено, открыто, скопировано или текущее. Где: теги (шапка статьи, карточки, проекты, поиск), ссылки `ABOUT` и проекта, `HOME`, шапка блока кода, строка поиска, складное оглавление, заголовок коллаута.
- **Ленты прогресса:** горящие клетки верхней ленты и ленты оглавления светятся одинаково (`--cell-glow`).
- **Три вида дизер-линий** (`LINE` в `lamp.ts`):
  1. `edge` — край шапки (сайта, таблицы): 2 ряда, плотный сверху.
  2. `bezel` — под безель-шапкой экрана (`.code-bar`, строка поиска, шапка складного оглавления) и вертикальный разделитель `ABOUT`: 2 ровных ряда (`EVEN2`), ни одна сторона не тяжелее.
  3. `row` — между строками одного списка (`tbody tr`, результаты поиска): `1px`.
  Акцентные линии (`hr`, полоска сноски на узком экране) — оранжевые, клетками `2px`.

## Главная страница, карточки и поиск

- Главная `/` двухколоночная (`max-w-[1100px]`): слева sticky-сайдбар `ABOUT` (`330px`) и вертикальный дизер-разделитель; справа секции `PROJECTS` и `ARTICLES`. Подписи секций и счётчики — IBM Plex Mono `11.5px` прописными (так же подписан блок «Linked from» под статьёй).
- Обе карточки — две трубки в одной рамке, высота `164px`, заголовок Source Serif `23px`, теги `11px`, без разделителя между половинами. У статьи: слева CRT-обложка с заголовком, датой и тегами, справа мини-монитор оглавления `.card-toc-monitor`. У проекта: слева чистая обложка (без CRT, на телефоне `3:2`), справа панель с заголовком, строкой описания и тегами. При наведении загорается рамка, фокус с клавиатуры обводит всю карточку «муравьями».
- Клик по тегу в шапке статьи (кнопка `[data-tag]`) открывает окно поиска с вбитым `#<тег>`; отдельных страниц тегов нет. Теги на карточках главной — просто подписи: клик по ним открывает саму статью.
- И лайтбокс, и окно поиска `⌘K` плавно открываются и закрываются (`160ms ease`, `@starting-style` + `allow-discrete`), с одной тенью `--shadow-modal`.
- Окно поиска устроено как блок кода: сверху безель с пикселем, полем ввода IBM Plex Mono с блочным курсором и `CLOSE [ESC]`, снизу дизерная линия; ниже экран `.search-screen` — тот же экран, что у блока кода. Фон страницы затемнён `--backdrop-bg`, без размытия.
- Результат поиска — строка-карточка: номер `01` шрифтом VT323 (приглушён, как ещё не прочитанный пункт оглавления), заголовок моно, строка меты как на карточках главной (`2026-11-19 · 7 MIN READ` и теги с оранжевыми квадратиками), фрагмент текста ровно в две строки, начинается с целого слова. Карточки разделены дизерной линией `1px`, как строки таблиц. У выбранной загораются номер и заголовок поверх шахматки `dither`; выбор ходит стрелками.
- Прокрутка выдачи — та же тонкая полоса, что у блоков кода, только вертикальная (`setupSearchScroll` в `lamp.ts`): серая направляющая `1px` и светлый ползунок `1.5px` с мягким свечением; тянется мышью, клик по направляющей перематывает. Нативная полоса скрыта. Рисуется на экране, под сеткой.

## Превью ссылок (`src/lib/og.ts`)

Картинки Open Graph 1200×630, которые показывают мессенджеры и соцсети, когда кидаешь ссылку. Собираются при сборке: `satori` верстает текст, `sharp` делает пиксели.

- Статья (`/og/<имя>.png`) повторяет свою карточку на главной: слева обложка-кинескоп (тёплый фосфор как в `covers.ts`, строки развёртки через 6px, мягкое свечение, виньетка, затемнение снизу под текст), на ней заголовок `Source Serif 4`, мета `2026-11-19 · 7 MIN READ` моно прописными и теги с оранжевыми квадратиками; справа мини-монитор `#1b1b1a` с оглавлением (номера VT323, названия IBM Plex Mono) под сеткой и стеклом; между ними дизерная линия. Без обложки слева тёмная карточка с оранжевой чертой.
- Сайт (`/og/site.png`, он же для страниц без своей картинки) повторяет главную: слева `ABOUT`, имя, описание, `github.com/rlwq` с пикселем; дизерная линия; справа монитор со списком статей, его высота растёт с числом статей.
- RGB-триад, как в браузере, нет: превью показывают уменьшенными примерно втрое, и триады превратились бы в муар. Строки развёртки крупные, чтобы пережить уменьшение.
- PNG с палитрой 256 цветов: на глаз то же самое, вес около 180 КБ вместо 780 (WhatsApp не показывает превью тяжелее ~300 КБ).
- Первый, простой вариант (обложка под затемнением, серифный заголовок, оглавление) сохранён в `og-plain.ts`; включается `OG_STYLE = 'plain'` в `og.ts`.

## Схемы (SVG в статьях)

SVG из `attachments/` встраиваются прямо в страницу (`inlineSvg` в `markdown-plugins.mjs`), поэтому видят CSS-переменные сайта. Схема — тот же «экранный» язык, что код и оглавление, а не картинка из чужого редактора.

- **Цвета только из токенов:** `--foreground`, `--muted-foreground`, `--border`, `--muted`, `--primary`; запасные значения в `var(…, #hex)` — из тёмной палитры. Один акцент — оранжевый `--primary`: то, на что надо смотреть (текущая клетка, активная команда, остановка). Никакого зелёного/синего «успеха».
- **Шрифт один — IBM Plex Mono** (`var(--font-mono)`). Код в узлах `500 13px`, `--foreground`. Метки (`REST`, `BODY`, `CURSOR`, `PROGRAM`, `HALTS IN 1`) — `10–10.5px`, прописными, разрядка `0.06em`, `--muted-foreground`; как мета в шапке статьи. Системного sans нет.
- **Узлы — как инлайновый `code`:** плашка `--muted`, рамка `1px` `--border`, скругление `3px`. Пустой / отброшенный узел — без заливки, рамка пунктиром `2 2`, текст приглушён. Ширина узла по тексту: `7.8px` на знак + `10px` поля с каждой стороны, не уже `52px`.
- **Геометрию схемы задаёт автор.** Раскладка узлов и форма связей (диагонали лесенкой, дуги, прямые углы) придуманы под конкретную схему; при переоформлении меняется только стиль — цвета, шрифт, толщины, скругления, — а не расположение. Связи тонкие, `1px`, `--muted-foreground` с прозрачностью около `0.5`; отброшенная ветка — пунктир `2 2`; стрелки маленькие. Подпись ребра — рядом с его серединой.
- **Горящее светится:** единица на ленте, рамка курсора, активная команда, узел остановки — `--primary` или `--foreground` с мягким фосфорным ореолом (SVG-фильтр `feGaussianBlur`), как ссылки и текст в коде. Остальное не светится.
- **Исходы в деревьях:** остановка — рамка `--primary` со свечением и метка `HALTS IN n`; программа, которая никогда не остановится, — та же рамка, приглушённая до 55 %, без свечения, и метка `NEVER HALTS`; узел, который раскрывается дальше, — `…` под ним.
- **Указатели — пиксельные:** стрелка-курсор собрана из квадратов `2px`, как пиксель-индикаторы; треугольников и скруглённых указателей нет.
- **SVG-картинка, а не схема** (экран приложения): атрибут `data-picture` на корневом `<svg>`. Правила выше к ней не применяются; лайтбокс показывает её как растровую картинку — без сетки, тёмной подложки и полей.
- **Края, уходящие в бесконечность** (лента), растворяются дизерингом по матрице Байера (клетки `2px`), а не плавным градиентом; как дизерные линии сайта.
- **Размер:** схема рисуется в ширину колонки текста, не шире `620px`, в целых координатах, линии `1px` на полупикселе — иначе браузер их ужмёт и размоет.
- **Анимация** — только когда она объясняет процесс (лента); у `prefers-reduced-motion` — финальный кадр без движения.

## Таблицы

- Полная ширина колонки (`display: table; width: 100%`), шапка `thead` в `IBM Plex Mono` прописными с 2-рядной `1×1px` дизерной линией снизу (плотный ряд сверху) и тихими разделителями между строками (без подсветки строк при наведении).

## Цитаты и коллауты (`>` и `> [!note]`)

- Оба вида — тёмная матовая распечатка в тон сайта (без глянца и CRT-виньетки): графитовая бумага `#181817` (`#f4f3f0` в светлой), едва заметные полосы прохода головки струйника по строкам (`24px` + микропроходы `6px`), перфорация `1px` (`4px` штрих / `4px` пропуск) сверху и снизу, сплошная цветная полоса-чернила `2px` слева.
- Текст набран `IBM Plex Mono` (`14px / 24px`) с лёгким растеканием чернил (`text-shadow: 0 0 0.7px`). Обычная цитата `>` — курсив `IBM Plex Mono` (`--muted-foreground`), код и внутренний курсив прямые, `strong` в `--foreground`, полоса оранжевая (`--primary`).
- Коллауты `> [!note]` / `[!tip]` / `[!warning]` / `[!danger]` / `[!quote]` — заголовок-штамп шрифтом `VT323` (`16px`, прописными, с фолбеком в `IBM Plex Mono`) и квадратным пикселем `4px`. У каждой группы свой цвет чернил (полоса, пиксель и заголовок): `note`/`info`/`example`/`question` — `--note` (синий), `tip`/`important`/`success` — `--tip` (зелёный), `warning`/`caution` — `--primary` (оранжевый, без жёлтого), `danger`/`error`/`bug` — `--danger` (красный), `quote` — `--muted-foreground` с курсивом.

## Технические подводные камни

- **Классы в `markdown-classes.mjs` не доходят до уже отрисованных статей:** Astro кеширует их в `.astro/`. Проще стилизовать через CSS (`global.css` или `lamp.css`), либо сбросить кеш.
- **После смены схемы коллекции** (`content.config.ts`) dev-сервер нужно перезапустить.
- **SVG-схемы и кеш статей.** Схема вшивается в статью при отрисовке, а Astro перерисовывает статью только при изменении её текста. Поэтому `prepare()` в `content.config.ts` подмешивает в хэш статьи отпечаток всех SVG из папки коллекции (`src/content/posts/`, `src/content/projects/`): правка схемы перерисовывает статьи и в сборке, и в dev сразу.
- **Черновики** (`draft: true`) выкидываются ещё при загрузке коллекции, их картинки в сборку не попадают. Файл остаётся в `src/content/posts/`, это же хранилище Obsidian.
- **Обложка** задаётся полем `cover: attachments/x.jpg` (схема `image()`); неверный путь ломает сборку.
- **Сайт опубликован** на GitHub Pages (`https://rlwq.github.io`): каждый пуш в `main` собирает и выкладывает его (`.github/workflows/deploy.yml`). Локально сборку можно посмотреть через `npm run build` и `npm run preview`.
- **Светлая тема не попадает в сборку:** плагин `dropLightTheme` в `astro.config.mjs` вырезает правило, если каждый селектор его списка про `[data-theme=light]` (запятые внутри `:is()` списком не считаются). Правило, где светлая тема смешана с общими селекторами, останется: пиши их отдельно.
- **Проверка в браузере.** Эффекты на canvas и `requestAnimationFrame` не работают в скрытой или фоновой вкладке: если «ничего не рисуется», сначала проверь, видна ли вкладка.
