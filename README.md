# Записки

Блог на Astro 7 + Tailwind CSS 4 для длинных статей: оглавление на полях, сноски на полях, формулы, выноски, код с кнопкой «Копировать», хэштеги, поиск, тёмная тема (светлая готова, но спрятана: `lightTheme` в `src/site.config.ts`).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # готовый сайт в dist/
npm run check    # проверка типов (astro check + tsc)
```

## Где что лежит

- `STYLE.md` — стилистика сайта: идея, правила, эффекты и где они живут. Читать перед правками внешнего вида.

- `src/content/posts/` — статьи в Markdown, адрес `/blog/<имя-файла>/`. Картинки — в `attachments/`. Папку можно открыть как хранилище Obsidian.
- `src/content/projects/` — проекты, адрес `/projects/<имя-файла>/`; на главной — карточки над статьями.
- `src/site.config.ts` — название, описание, меню, флаг светлой темы.
- `astro.config.mjs` — адрес сайта (`site`) и настройки Markdown.
- `src/styles/global.css` — токены: палитра (цвета для `bg-background`, `text-primary`, `text-muted-foreground`…), поверхности, тени, свечение, тайминги; шрифты.
- `src/styles/lamp.css` и `src/scripts/lamp.ts` — «ламповые» эффекты: свечение, кинескоп, дизеринг (см. `STYLE.md`).
- `src/styles/markdown-classes.mjs` — Tailwind-классы для текста статей: какой класс получает каждый `h2`, `p`, ссылка, выноска, сноска.
- `src/components/` — вёрстка на Tailwind-классах: шаблон статьи и проекта, карточки главной, оглавление, поиск, шапка страниц.
- `src/layouts/Base.astro` — каркас страницы: шапка с меню, поиск, тема.
- `src/pages/index.astro` — текст на главной.
- `src/lib/markdown-plugins.mjs` — `[[ссылки]]`, сноски на полях, выноски, формулы, шапка у кода.

## Особенности Markdown в этом блоге

Поля в начале статьи:

```yaml
---
title: Заголовок            # обязательно
description: Одна строка    # для списка статей, поиска, RSS и соцсетей
date: 2026-11-03            # дата публикации
updated: 2026-11-10         # необязательно
tags: [ML, Python]          # хэштеги, сколько угодно
draft: true                 # черновик: на сайт не попадёт, его картинки тоже; файл остаётся в папке
toc: false                  # оглавление; само появляется при 3+ разделах ##
cover: attachments/x.jpg    # обложка карточки на главной и OG-картинки; неверный путь — ошибка сборки
coverPosition: top          # кадрирование обложки: top, center (по умолчанию), bottom
---
```

Сверх обычного Markdown:

- `[[имя-файла]]`, `[[имя-файла|текст]]`, `[[имя-файла#Раздел]]` — ссылки на другие статьи, попадают в «Ссылаются на эту статью».
- `текст[^1]` + `[^1]: пояснение` — сноска на правом поле.
- `> [!note] Заголовок` — выноска; типы `note`, `tip`, `warning`, `danger`, `quote`.
- ```` ```python title="crops/data.py" ```` — имя файла в шапке блока кода.
- `$x^2$` и `$$ … $$` — формулы (KaTeX).
- Курсивная строка сразу под картинкой — подпись к ней.
